# Credits

FromZoid is original Lua and scripts written for Project Zomboid Build 42.20.

Behavior was inspired by (not copied from) these Workshop mods:

- Zombies Fear The Sun / Fear the Sun +Nests — day indoor hiding, night emergence
- Lingering Whispers — zombies speaking near the player
- Random Zombies - Day and Night — separate day/night zombie lore
- The Darkness Is Coming! — rare blackout / fog events
- Barricaded World - Extended Erosion — pre-damaged, boarded houses

Do not redistribute those mods' files with this pack.
